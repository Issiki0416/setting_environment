# スクリーンショット自動化スクリプト（macOS / AppleScript）

## 概要

本スクリプトは、アプリ上で**自動でページ送りしながらスクリーンショットを保存**するためのAppleScriptです。
指定したページ数分、繰り返し処理を行います。

---

## 必要な設定

### アクセシビリティ許可

以下をONにする必要があります：

- システム設定 → プライバシーとセキュリティ → アクセシビリティ
- Script Editorなど

👉 許可しないとページ送りが動作しない

---

## ⚠️ 注意点

### 1. キー操作が環境依存

環境によってページ送りキーが異なる場合があります：

| 操作     | キーコード |
| -------- | ---------- |
| →キー    | 124        |
| PageDown | 121        |
| スペース | 49         |

👉 動かない場合は変更してください

---

### 2. 待機時間の調整

PCが重い時ページ送りがうまくいかない時がある。
